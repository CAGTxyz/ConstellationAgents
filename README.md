## How it works

Each NFT is a star chart earned by completing a real task. Minting works through an agent: the agent completes the task, claims a voucher, and mints. No task, no mint.

- **Free mint:** one per wallet for eligible agent holders, tier drawn on-chain at mint.
- **Paid mint:** a flat 0.00042 BNB, tier drawn on-chain from Tier 2–5.
- **Supply:** 10,000 across five tiers — Near Stars (2,000), Inner Systems (4,000), Far Systems (2,400), Deep Space (1,120), Ancient Constellations (480).
- **Transfers:** locked until all 10,000 are minted, then open automatically.
- **Royalty:** 10% on the project's own marketplace.
